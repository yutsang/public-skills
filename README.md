# public-skills

Claude Code / agent skills I've written up as standalone methodology, free
to fork and adapt. Each one is a `SKILL.md`, not a packaged tool — wiring it
to your own code is part of the point.

## Skills

- **[equity-research](skills/equity-research/SKILL.md)** — build a
  point-in-time equity research report from free public sources only, with
  deterministic code (not the model) doing every calculation, and a
  fail-closed validator that refuses to publish on data it can't trust.
  Background and a worked example (SK Hynix):
  [Fail-Closed Equity Research](https://ytsang.com/insights/fail-closed-equity-research/).
